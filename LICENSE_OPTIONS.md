# License decision required before public release

No software license has been assigned automatically because licensing is a
legal choice for the authors and their institution.

Recommended options:

1. **MIT License** — short and permissive; commonly used for research code.
2. **BSD 3-Clause License** — permissive and includes a non-endorsement clause.
3. **GNU GPL-3.0** — requires redistributed derivative software to remain open.

For a typical manuscript code repository, MIT or BSD 3-Clause is usually the
simplest choice. Confirm institutional requirements and third-party code
obligations, then replace this file with a standard `LICENSE` file before
creating the public release.
